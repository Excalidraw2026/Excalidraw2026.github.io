家装 CRM
管理系统

为家装销售场景自研的客户管理系统——一个人 + AI 从零搭起来。把客户从「脑子里」搬进「系统里」。

01

在线体验

Live Demo
▶ 静态演示版 · 内置演示数据 · 管理员 admin / 123456 · 销售 sales / 123456

这是一个纯前端静态演示版：不用装 Python、不用数据库，双击即可打开体验完整界面与交互。数据为演示样例，不会真实保存。想跑真数据，见下方「本地运行」。

02

功能

Features
客户档案管理增删改查 + 客户来源，一个客户一份完整档案。
关键节点跟踪量房 / 到店 / 定金 / 签约时间，里程碑一目了然。
预计签约金额每个客户能签多少，心里有数。
多条件筛选按创建、量房、到店、定金、签约组合筛选，如「本月量房未签约」。
管道视图 / 客户池客户分布一屏看清，公海客户待认领与再分配。
跟进记录每次跟进留痕，不靠记忆。
角色权限管理员看全部，销售只看自己的客户。
老板数据看板客户、节点、金额聚合，一屏看全局。
自动备份 + 无损迁移升级加字段不丢数据，启动前自动备份。
03

技术栈

Stack
Python · Flask · SQLite · 原生前端单页 > 架构：models.py（建表/迁移/备份）→ app.py（API/看板）→ static/index.html（单页前端）
04

本地运行

Run
$ python app.py > 浏览器打开 http://127.0.0.1:5000/ > 管理员 admin / 销售 sales
