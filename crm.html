家装 CRM 管理系统

为家装销售场景自研的客户管理系统——一个人 + AI 从零搭起来。

背景

做家装销售，客户跟进靠脑子记、微信翻记录，量房、定金、签约这些关键节点全靠人肉盯。这个系统就是为解决这个问题而生的：把客户从"脑子里"搬进"系统里"。

功能
  • 客户档案管理增删改查 + 客户来源，一个客户一份完整档案。
  • 家装关键节点跟踪量房时间 / 到店 / 定金 / 签约时间，里程碑一目了然。
  • 预计签约金额每个客户能签多少，心里有数。
  • 时间多条件筛选按创建、量房、到店、定金、签约任意组合筛选，比如"本月量房未签约"。
  • 跟进记录每次跟进留痕，不靠记忆。
  • 角色权限管理员看全部，销售只看自己的客户。
  • 老板数据看板客户、节点、金额聚合，一屏看全局。
  • 数据库自动备份 + 无损迁移升级加字段不丢数据，启动前自动备份。
技术栈
Python · Flask · SQLite · 原生前端单页 > 架构：models.py（建表/迁移/备份）→ app.py（API/看板）→ static/index.html（单页前端）
本地运行
$ python app.py > 浏览器打开 http://127.0.0.1:5000/ > 管理员 admin / 销售 sales
