这个站是怎么做的

一个人 + AI = 一个团队。

为什么建站

因为一句话："必须边长新能力，边让他人看见。"做了东西，就要有一个地方让别人看见。于是有了这个站。

技术方案
  • 纯静态HTML + CSS + JS，零依赖、零后端，双击就能打开，任何免费托管都能跑。
  • 终端开场whoami / cat about.md / ls —— 用命令行讲自我介绍，是整站的签名。
  • 门户结构主页是入口，每张卡片一个子页面：作品、文章、灵感、联系。
  • 设计规范参考 esther-design-system（CC BY-NC-SA 4.0），已署名。
过程
$ whoami → 我是谁 $ cat about.md → 我信什么 $ ls ~/works → 我做过什么 $ ./launch.sh → 上线，让别人看见

从提需求到成型，全程和 AI 搭档：我定方向、给素材，AI 写代码、调样式、跑验证。一天之内，从想法变成了能打开的站。

成本

域名 0 元（GitHub Pages 免费托管），服务器 0 元，工具 0 元。唯一投入的是认真。
